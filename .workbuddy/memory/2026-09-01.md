# 2026-09-01

## AI 生图节点三项改进（backend/blocks/image_generate.py + frontend/canvasflow/src/components/BindableInput.tsx）

1. **不再覆盖旧图**：默认 `filename_mode=timestamp`，保存名带 `YYYYmmdd_HHMMSS` 时间戳（如 `gen_20260901_143000_1.png`），秒级撞名自动追加序号；`fixed` 模式保留旧的固定文件名覆盖行为（显式 save_path 流程兼容）。
2. **图生图（图片编辑）**：新增 `mode` 参数（text2img / img2img）+ `source_image` 参考图输入（支持本地路径 / URL / data URL / 上游数组绑定取首个）。img2img 走 OpenAI 兼容 `/images/edits` multipart 端点（`_request_image_edits`、`_build_edit_form`、`_load_source_image`）。
3. **预览增强**：输出面板原本只有顶层字符串图片路径可悬停预览（ImagePathLink）；新增 `ImageThumbStrip` 组件，数组/对象输出（如 paths）里的图片路径渲染为内联缩略图，点击放大（复用 LocalImagePreviewDialog + bridge.readLocalImage）。

测试：backend/test_image_generate.py 更新 + 新增 8 个用例，全套 139 passed；前端 tsc --noEmit 通过。

注意：项目可用 pytest 在系统 Python 3.12（`C:\Users\Administrator\AppData\Local\Programs\Python\Python312\python.exe`），托管 3.13 无 pytest。
